# Jam'a Global Chat

غرفة دردشة عامة صغيرة لـ 5 أو 6 أشخاص. يكتب كل شخص اسمه ويدخل مباشرة، دون حساب أو كلمة مرور.

## Features

- تحديث آمن للرسائل وحالة المستخدمين عبر جلسات الخادم.
- اسم محلي يمكن تغييره في أي وقت.
- عرض عدد المتصلين حاليًا.
- تصميم متجاوب للهاتف والكمبيوتر.
- آخر 100 رسالة عند فتح التطبيق.
- تمرير مستقل للرسائل مع بقاء مربع الكتابة ظاهرًا.
- أوامر عامة وإدارية من مربع الرسالة دون أزرار حذف.
- كلمة إدارة مشفرة لا تظهر في كود الموقع أو الرسائل.
- لا توجد خطوة بناء أو حزم npm.

## 1. Create Supabase project

1. افتح [supabase.com](https://supabase.com) وسجّل الدخول بحساب GitHub.
2. أنشئ مشروعًا جديدًا ضمن الخطة المجانية.
3. افتح `SQL Editor` ثم الصق محتوى ملف `supabase.sql` وشغّله مرة واحدة.
4. افتح `admin-commands.sql` وغيّر `CHANGE_THIS_ADMIN_PASSWORD` إلى كلمة إدارة خاصة من 20 محرفًا عشوائيًا على الأقل، ثم شغّل الملف كاملًا في `SQL Editor`.
5. شغّل `security-hardening.sql` ثم `whitelist-mode.sql` في `SQL Editor` لتفعيل جلسات الخادم والقائمة البيضاء.
6. افتح `Project Settings > API` وانسخ `Project URL` و`anon public key`.
7. افتح `config.js` وضع القيمتين:

```js
window.CHAT_CONFIG = {
  supabaseUrl: "https://YOUR_PROJECT.supabase.co",
  supabaseAnonKey: "YOUR_ANON_PUBLIC_KEY",
};
```

استخدم مفتاح `anon public` فقط. لا تضع مفتاح `service_role` داخل الموقع.

إذا كان جدول الرسائل موجودًا من إصدار سابق ومحميًا بالفعل، شغّل `whitelist-mode.sql` لإزالة رمز الغرفة وإضافة موافقات الجلسات دون حذف الرسائل القديمة.

## Chat commands

اكتب `/help` داخل مربع الرسالة لعرض جميع الأوامر. الأوامر العامة هي `/name` و`/me` و`/shrug` و`/users`.

استخدم `/notify` لتفعيل إشعارات المتصفح وصوت الرسائل الجديدة، و`/mute` لتعطيلهما. يمكن التحكم بالصوت وحده عبر `/sound on` و`/sound off`. يجب أن يفعّل كل مستخدم الإشعارات بنفسه، وتعمل التنبيهات ما دامت الصفحة مفتوحة أو في الخلفية.

لتفعيل الإدارة في تبويبك الحالي استخدم:

```text
/admin YOUR_PRIVATE_PASSWORD
```

بعدها تتاح أوامر الإدارة والحذف والقفل والقائمة البيضاء. استخدم `/active` لعرض الجلسات ثم `/allow ID` للسماح، و`/white off` للسماح للجميع. أثناء `/lock` لا تُقبل رسائل عادية من أي جلسة، ويستطيع المدير تنفيذ `/unlock` فقط من الحقل الإداري.

## 2. Test locally

شغّل خادمًا محليًا من داخل مجلد المشروع:

```bash
python3 -m http.server 8080
```

ثم افتح:

```text
http://localhost:8080
```

يمكنك فتح نافذتين خاصتين بأسماء مختلفة لتجربة المحادثة.

## 3. Publish with GitHub Pages

1. أنشئ مستودع GitHub جديدًا، مثل `mini-global-chat`.
2. ارفع جميع الملفات الموجودة في هذا المجلد إلى جذر المستودع.
3. افتح `Settings > Pages` في المستودع.
4. اختر `Deploy from a branch` ثم فرع `main` والمجلد `/ (root)`.
5. انتظر دقيقة، وسيظهر رابط الموقع في صفحة `Pages`.

## Important limitation

لا توجد حسابات فردية للمستخدمين. تنشئ قاعدة البيانات جلسة عشوائية لكل متصفح، وتتحكم القائمة البيضاء في قدرتها على القراءة والكتابة، كما أن أوامر الإدارة محمية بكلمة مشفرة. لا تضع كلمة الإدارة في `config.js` أو GitHub ولا ترسلها كرسالة عادية.

هذا يمنع القراءة والكتابة المباشرتين عبر REST دون جلسة، لكنه ليس تشفير طرف إلى طرف؛ يستطيع مالك مشروع Supabase قراءة محتوى الرسائل من لوحة قاعدة البيانات.
